## 🇨🇳 简体中文设置步骤（只需 1 分钟）

### 第 1 步：导入快捷指令并填密钥
1. 在 iPhone 上用 **Safari 浏览器** 点击上面推荐的 **[Doraemon-Gemini.shortcut](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-Gemini.shortcut)**。
2. 点「下载」→ 打开文件，系统会自动跳到「快捷指令」App 并弹出设置向导：
   - 第 1 项：粘贴你的 **API Key**（Gemini / OpenAI / DeepSeek）。
   - 第 2 项：输入想翻译成的语言（默认 `简体中文`，也可以填 `ภาษาไทย`、`English`、`日本語`、`한국어`）。
   - 第 3 项：模型名保持默认即可，点「添加快捷指令」。

### 第 2 步：绑定「轻点背面两下」（最顺手！）
1. 打开 iPhone **设置** → **辅助功能** → **触控** → 滑到最底部点 **轻点背面**。
2. 点 **轻点两下**（或轻点三下），往下滑到「快捷指令」分组，选中 **机器猫-截屏翻译(Gemini)**。
3. 以后在 Tinder 聊天时，轻敲两下手机背面即可原地弹出翻译！
   - *首次运行时系统会弹窗询问“允许截屏”和“允许连接网络”，全部点 **始终允许** 即可，以后不再询问。*
   - *如果你不想敲背面，也可以在 **辅助功能 → 触控 → 辅助触控（小白点）** 或 iPhone 15 Pro / 16 系列的 **操作按钮** 上绑定同一个快捷指令。*

## 🇹🇭 คำแนะนำภาษาไทย (สำหรับ iPhone ไม่ต้องติดตั้งแอป)

ใช้ฟีเจอร์ **คำสั่งลัด (Shortcuts)** ที่มีมาใน iPhone ฟรีถาวร ไม่ต้องต่อคอม ไม่หมดอายุทุก 7 วัน แค่**แตะด้านหลังเครื่อง 2 ครั้ง**ระหว่างแชท Tinder คำแปลภาษาไทยจะเด้งขึ้นมาทันทีโดยไม่บันทึกรูปลงอัลบั้ม

### ขั้นตอนที่ 1: เพิ่มคำสั่งลัดและใส่คีย์ AI
1. เปิดลิงก์นี้ด้วย **Safari** บน iPhone 👉 **[Doraemon-Gemini.shortcut](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-Gemini.shortcut)** (แนะนำสำหรับภาษาไทย เพราะอ่านภาษาไทยและภาษาจีนได้แม่นยำมาก)
2. กดดาวน์โหลดแล้วแตะเปิดไฟล์ → กด **ตั้งค่าคำสั่งลัด (Set Up Shortcut)**
3. วาง **Gemini API Key** ของคุณ → ช่องภาษาเป้าหมายให้พิมพ์ **`ภาษาไทย`** → กด **เพิ่มคำสั่งลัด (Add Shortcut)**

### ขั้นตอนที่ 2: ตั้งค่าแตะด้านหลังเครื่อง 2 ครั้ง
1. ไปที่ **การตั้งค่า (Settings)** → **การช่วยการเข้าถึง (Accessibility)** → **สัมผัส (Touch)** → เลื่อนลงล่างสุดกด **แตะด้านหลัง (Back Tap)**
2. เลือก **แตะสองครั้ง (Double Tap)** → เลื่อนลงไปที่หัวข้อคำสั่งลัด แล้วเลือก **机器猫-截屏翻译(Gemini)**
3. เมื่อเปิดแชท Tinder แค่แตะด้านหลัง iPhone 2 ครั้ง คำแปลภาษาไทยจะเด้งขึ้นมาทันที (ครั้งแรกที่ใช้งาน ให้กด **อนุญาตเสมอ / Always Allow** เมื่อระบบถามสิทธิ์จับภาพหน้าจอและเชื่อมต่ออินเทอร์เน็ต)

## 🇬🇧 English Setup Guide (iPhone, Zero App Install)

1. Open **[Doraemon-Gemini.shortcut](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-Gemini.shortcut)** in **iPhone Safari** and tap **Set Up Shortcut**.
2. Paste your **API Key**, set target language (e.g. `English`, `ภาษาไทย`, `简体中文`, `日本語`, `한국어`), and tap **Add Shortcut**.
3. Go to **Settings → Accessibility → Touch → Back Tap → Double Tap** and choose **机器猫-截屏翻译(Gemini)**.
4. Inside Tinder chat, double-tap the back of your iPhone. On the first run, choose **Always Allow** for screenshot and network prompts.
