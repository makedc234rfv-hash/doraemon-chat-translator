## 🇨🇳 简体中文使用说明

### 📥 下载与安装
1. 直接点击下载 **[Doraemon-v1.2.0.apk](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-v1.2.0.apk)** 到安卓手机安装（装好后桌面名称显示为 **机器猫**）。
2. 打开 **机器猫**，顶部选择界面语言，以及回复润色的目标语言（默认「**自动跟对方**」，也可指定泰语/英语等）和说话口吻（男生 `ครับ` / 女生 `ค่ะ` / 轻松中性）。
3. 点「**去开启开关**」找到「**机器猫**」开启（Android 13+ 如提示受限设置，先点「**去应用详情**」→ 右上角三个点 →「**允许受限设置**」再回去开）。
4. 填上你的 AI 密钥（支持 Gemini / DeepSeek / OpenAI / 自定义兼容接口），点「**保存并测试翻译**」通过即可。

### ✨ 回复润色怎么用（告别生硬机翻泰语）
1. 在 Tinder 聊天输入框里直接打**中文**（或者输入法翻出来觉得很生硬的泰语）。
2. 点悬浮卡片底部的「**✨ 润色回复**」（卡片收起时直接点右侧小胶囊下方的「**润**」）。
3. AI 会结合当前聊天语境，生成 **「自然地道」** 和 **「轻松暖一点」** 两个地道版本，每条下面都附中文意思方便你确认。
4. 点「**填入**」自动替换进 Tinder 输入框，直接发送即可！

### 🔒 隐私与安全范围说明
本软件为开源工具，**仅用于 Tinder 跨语言聊天翻译与回复润色，方便日常沟通**：
- ✅ **绝不读取通讯录**、相册、短信、通话记录、定位或任何账号密码。
- ✅ 仅申请基础网络权限（用于直连你填写的 AI 翻译接口），无多余权限。
- ✅ 仅在 Tinder 聊天界面内工作，切出 Tinder 或切到刷卡页自动隐藏。
- ✅ 无任何中转服务器、无广告、无埋点统计，全部代码公开可查。

## 🇬🇧 English Guide

**机器猫 (Doraemon Chat Translator)** auto-translates incoming foreign messages in Tinder chat AND polishes your draft replies into natural, native-sounding Thai/English/Chinese/Japanese/Korean (with back-translation and 1-tap auto-fill into the chat box).

### 📥 Download & Setup
1. Direct download **[Doraemon-v1.2.0.apk](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-v1.2.0.apk)** and install on Android (Android 8.0–15+).

- **Never accesses** contacts, photos, SMS, call logs, location, or passwords.
- **Tinder-only scope**: stays completely hidden outside Tinder chat screens.
