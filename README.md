## 🇨🇳 简体中文使用说明

### 📥 下载与安装
1. 直接点击下载 **[Doraemon-v1.1.0.apk](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-v1.1.0.apk)** 到安卓手机安装（装好后桌面名称显示为 **机器猫**）。
2. 打开 **机器猫**，顶部可自由切换界面和翻译目标语言（支持 **中文 / ไทย / English / 日本語 / 한국어**）。
3. 点「**去开启开关**」找到「**机器猫**」开启（Android 13+ 如提示受限设置，先点「**去应用详情**」→ 右上角三个点 →「**允许受限设置**」再回去开）。
4. 填上你的 AI 密钥（支持 Gemini / DeepSeek / OpenAI / 自定义兼容接口），点「**保存并测试翻译**」通过即可。
5. 支持「**打开模拟聊天测试**」先看效果；悬浮卡片支持拖拽、一键切换 **小 / 中 / 大** 尺寸，并自动适配不同手机屏幕。

### 🔒 隐私与安全范围说明
本软件为开源工具，**仅用于 Tinder 跨语言聊天翻译，方便日常沟通**：
- ✅ **绝不读取通讯录**、相册、短信、通话记录、定位或任何账号密码。
- ✅ 仅申请基础网络权限（用于直连你填写的 AI 翻译接口），无多余权限。
- ✅ 仅在 Tinder 聊天界面内读取当前对话气泡，切出 Tinder 或切到刷卡页自动隐藏。
- ✅ 无任何中转服务器、无广告、无埋点统计，全部代码公开可查。

## 🇬🇧 English Guide

**机器猫 (Doraemon Chat Translator)** automatically translates incoming foreign messages inside Tinder chat using your own AI API key, with support for **Chinese, Thai, English, Japanese, and Korean** UI & target languages.

### 📥 Download & Setup
1. Direct download **[Doraemon-v1.1.0.apk](https://github.com/makedc234rfv-hash/doraemon-chat-translator/releases/latest/download/Doraemon-v1.1.0.apk)** and install on Android (Android 8.0–15+).
2. Open **机器猫**, select your preferred language at the top.
3. Enable **Accessibility Service** for **机器猫** (on Android 13+, tap **App Info** → top-right 3 dots → **Allow restricted settings** first).
4. Enter your AI API key (**Gemini / DeepSeek / OpenAI / Custom**) and tap **Save & Test**.

### 🔒 Privacy & Safety Scope
- **Built solely for Tinder chat translation** to make cross-language communication effortless.
- **Never accesses** contacts, photos, SMS, call logs, location, or passwords.
- **Tinder-only scope**: stays completely hidden outside Tinder chat screens.
- **Zero relay servers, zero ads, zero tracking**: talks directly to the AI provider you configure. Full source code is open in this repository.
